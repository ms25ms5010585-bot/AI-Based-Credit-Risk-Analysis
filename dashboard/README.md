# Credit Risk Analysis Dashboard

## Overview
This folder contains the Power BI dashboard documentation for the AI-Based Credit Risk Analysis and Prediction in Banking project.

The dashboard is designed to visualize customer credit information, historical risk categories, and machine learning model performance.

## Dashboard Objectives
- Analyze the distribution of good-risk and bad-risk records.
- Explore credit amount and loan duration patterns.
- Compare customer characteristics across historical risk categories.
- Present key classification model evaluation metrics.
- Support data-driven business analysis through visualizations.

## Key Performance Indicators (KPIs)
- Total customer records
- Good-risk records
- Bad-risk records
- Good-risk and bad-risk percentages
- Model accuracy
- Model precision, recall, and F1-score

## Planned Visualizations
1. **KPI Cards:** Total records and risk-category counts.
2. **Donut Chart:** Distribution of historical risk categories.
3. **Bar Chart:** Risk category by loan purpose.
4. **Column Chart:** Credit amount by risk category.
5. **Scatter Chart:** Credit amount versus loan duration.
6. **Model Performance:** Classification evaluation metrics.

## Limitations
The dataset contains historical risk labels. These labels should not be interpreted as confirmed future loan defaults. The analysis is intended for academic purposes and should not be used as the sole basis for real loan approval decisions.
