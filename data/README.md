# Dataset Information

## Project
AI-Based Credit Risk Analysis and Prediction in Banking

## Dataset Name
German Credit Dataset

## Expected File
`german_credit_data.csv`

## Description
This dataset contains customer information and historical credit-risk categories. It includes attributes such as age, job, housing, savings account, checking account, credit amount, loan duration, loan purpose, and risk category.

## Purpose
The dataset is used for educational data analysis and machine learning experiments, including:
- Data cleaning and preprocessing
- Logistic Regression classification
- K-Means customer segmentation
- Model performance evaluation

The dataset is used for academic purposes only. Verify the source and licence before redistributing the original data. If the dataset is not included in this repository, download it from the verified source and save it as `german_credit_data.csv` before running the notebook.
